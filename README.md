# makemore

Character-level name generator, built up from simple statistical models to neural nets, following Karpathy's makemore series.

## Quickstart

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m ipykernel install --user --name=makemore --display-name "Python (makemore)"
jupyter notebook makemore.ipynb
```

Select the "Python (makemore)" kernel when the notebook opens.
